# Report Variables — template.yaml

This file is the **single source of truth** for every variable in the report
template. The AI agent (or a human) collects values for these variables, then
performs a global find-and-replace of the `{{VARIABLE}}` tokens in the `.qmd`
files.

## How to use

1. Ask the user (or the agent that generated this scaffold) for the values
   below. If the user has no strong preference, use the `default`.
2. Replace every occurrence of `{{VARIABLE}}` in the `.qmd` files with the
   collected value.
3. Replace `{{CREATOR}}` (the AI agent / assistant name) and address, and
   `{{SUPERVISOR_NAME}}` / `{{SUPERVISOR_TITLE}}`.
4. Remove this file (`template.yaml`) once substitution is done, or keep it
   as documentation — it is harmless.

## FAQ

**Why do tables have `\newline`{=latex}?** Quarto pipe tables with long
monospace tokens (paths, code identifiers) are rendered by Pandoc as a single
unbreakable `\texttt{}` string. In `longtable`, an over-long token would break
at column edges with an ugly hyphen. Hard line breaks at logical points
(`/`, `_`) keep each cell tidy)Skip. Just document this in README.
